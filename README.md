# SUAT 课表

**深圳理工大学课表助手**，随时随地查看课程安排，轻松掌握每周课表。

</div>

---

## 这是什么

SUAT 课表是一款帮助深圳理工大学同学查看课程安排的应用。登录教务系统后，即可获取你的课表，并以清晰的周视图卡片形式展示每一门课程的时间、教室、老师和学分。

## 主要功能

- **周视图课表**：一目了然查看 12 节课 × 5 天的课程安排，可左右切换周次，自动定位到当前周。
- **两种登录方式**：支持「账号密码」或「手机号短信验证码」登录，怎么方便怎么来。
- **新建课程**：没有排到的课也能手动添加，自由管理自己的课表。
- **自定义课程卡片**：给每门课挑选喜欢的颜色，选择卡片上显示老师、教室还是学分。
- **个性化背景**：从相册选一张喜欢的图片作为课表背景（支持动图），随时换新。
- **外观随心调**：表头高度、行高、配色、今天高亮等都能按喜好调整，还可以一键恢复默认。
- **本地保存**：课表只保存在你自己的设备上，无需担心数据上传到别处。

## 使用方式

1. 在首页右上角菜单中点击「登陆导入课表」。
2. 阅读并同意隐私协议，设置本学期第一周日期。
3. 确认删除原有课程后，选择登录方式完成登录。
4. 登录成功后，课表会自动更新显示。

登录后课程就会一直保存在本地，下次打开无需重复登录。

## 温馨提示

- 账号密码仅用于本次登录获取课表，不会保存在本地。
- 登录会话有效期为 3 分钟，获取验证码后请尽快完成登录。
- 忘记密码可前往教务系统找回。
